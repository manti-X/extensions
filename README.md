### Give the repo a :star:

Extension repository for **Mihon and its forks**.

This repo contains extensions that cannot be added to Keiyoushi.\
Some extensions may lift certain restrictions or offer better quality compared to extensions from Keiyoushi.

Repo link:
```
https://github.com/manti-X/extensions/raw/repo/index.pb
```
[Click here to install this repo](https://intradeus.github.io/http-protocol-redirector/?r=mihon://extension-store?url=https://github.com/manti-X/extensions/raw/repo/index.pb)

Supported Apps:
- Mihon 0.21.3+
- Komikku 1.14.1+
- TachiyomiSY 1.13.2+
- TachiyomiJ2K 1.8.1+
- TachiyomiAZ 8.9.1+/Android 8+

If you encounter an issue, want to request a feature, or want to request a new source, [open an issue](https://github.com/manti-X/extensions/issues).

Before opening an issue, please verify that your app and its version are supported and that the issue is reproducible with the latest version of the extension.
