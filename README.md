Extension repository for Mihon and its forks.

This repo contains extensions that cannot be added to Keiyoushi.\
Some extensions may lift certain restrictions or offer better image quality compared to extensions from Keiyoushi.

Repo link:
```
https://github.com/manti-X/extensions/raw/repo/index.pb
```
[Click here to install this repo](https://intradeus.github.io/http-protocol-redirector/?r=mihon://extension-store?url=https://github.com/manti-X/extensions/raw/repo/index.pb)

Supported Apps:
- Mihon 0.20.1+
- Komikku 1.14.0+
- TachiyomiSY 1.13.2+
- TachiyomiAZ 8.9.0+/Android 8+

If you encounter an issue or want to request a feature, open an issue.\
Before opening an issue, please verify that your app and its version are supported.
